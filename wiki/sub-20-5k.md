# Sub-20 min 5k

## Goal
Break 20 minutes for 5k (4:00/km). No target date set yet. Current 5k PB is 22:09 (4:26/km, Strava, ~Aug 2026 — not in Fitbit). Fitbit now covers all runs going forward. Gap to sub-20 is ~2 minutes; a realistic 3–6 month target with consistent structured work.

## Approach
3 runs per week:
- **Quality session** (Tue or Wed): intervals or tempo at or near 4:00/km target pace. Main adaptation driver.
- **Long easy run** (Fri): 10–14 km at 5:40–6:00/km. Builds aerobic base. Friday is a social run with a friend — use it as the long run regardless of exact pace.
- **Moderate run** (Sun or as needed): 5–8 km easy to easy-moderate.

3 gym sessions per week alongside (2 upper, 1 lower). Gym days sit between run days where possible to allow recovery.

Flexibility: the Friday social run replaces the long run slot. If a session is missed or swapped, reshape the week around it rather than doubling up.
